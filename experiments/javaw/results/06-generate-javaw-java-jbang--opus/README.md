# javaw

`javaw` generates a small, relocatable POSIX `sh` launcher script for a Java program.
It is written in Java as a single [JBang](https://www.jbang.dev) script (`javaw.java`).
The generated wrapper is the product: `javaw` never builds, bundles, or launches anything.

## Run it

```sh
jbang javaw.java --help        # or: ./javaw.java --help  (the file is executable)
jbang app install javaw.java   # optional: puts `javaw` on your PATH
```

```sh
$ javaw Tool.java                       # -> ./run-tool: exec java "$dir/Tool.java" "$@"
$ javaw --jar build/my-tool.jar         # -> ./run-my-tool: exec java -jar "$dir/build/my-tool.jar" "$@"
$ javaw --min-java 21 --jvm-opts "-Xmx512m" --classpath 'lib/*' -o bin/ HTTPServer.java
wrote /path/to/bin/run-http-server
$ bin/run-http-server --port 8080
```

A generated wrapper (`javaw --min-java 17 Tool.java`):

```sh
#!/bin/sh
# Generated by javaw. Regenerate with:
#   javaw --min-java 17 Tool.java
self=$0
case $self in /*) ;; *) self=./$self ;; esac
while [ -h "$self" ]; do
  link=$(readlink -- "$self")
  case $link in /*) self=$link ;; *) self=${self%/*}/$link ;; esac
done
dir=$(CDPATH= cd -P -- "${self%/*}/" && pwd -P) || exit 1
version=$(java -version 2>&1 | sed -n 's/.* version "\([^"]*\)".*/\1/p' | head -n 1)
major=${version#1.}
major=${major%%[!0-9]*}
if [ -z "$major" ] || [ "$major" -lt 17 ]; then
  echo "error: Java 17 or newer is required (found: ${version:-none})" >&2
  exit 1
fi
exec java "$dir/Tool.java" "$@"
```

How it works:

- The wrapper follows symlinks to itself (chains and relative targets) with plain `readlink`, then gets its real directory with `cd -P` and `pwd -P`.
- It puts `./` in front of relative paths and clears `CDPATH`, so CDPATH and names starting with `-` can't misdirect it.
- The program path is stored relative to the wrapper, so you can move or rename the wrapper as long as the program moves with it.
- `--classpath` and `--java-home` paths are written exactly as given. `--jvm-opts` text goes into the launch line verbatim, so normal shell quoting inside it works.

## Test

```sh
jbang JavawTest.java
```

This needs no setup beyond JBang. It checks:

- **Unit:** the kebab-case naming rules, shell quoting, CLI errors, wrapper contents, overwrite/`--force`, `-o` handling and the executable bit.
- **End to end:** it writes `Hello.java`, generates wrappers and runs them:
  - from a different directory;
  - through a relative symlink and through a chain of two;
  - with `JAVA_TOOL_OPTIONS=-Dapp.version=2` (together with `--min-java`);
  - with `CDPATH` exported while the wrapper is invoked as `app/run-hello` and a decoy `$CDPATH/app` exists;
  - after being moved and renamed into a directory whose name starts with `-`;
  - with a `--java-home` launch and a jar launch.
- **Version check:**
  - a too-old Java gives the clear error;
  - a missing Java gives the same error with `found: none`;
  - fake JVMs that report `1.8.0_392` and `28-ea` behind a JAVA_TOOL_OPTIONS notice are read as 8 and 28.
