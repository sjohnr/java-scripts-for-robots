# Java Scripts for Robots: Yesterday, Today, and Tomorrow

> Ask AI to build a CLI and it writes Python. Is that a statement about AI or about Java? What would it take for Java to be a real answer?
> 
> I ran into this while building small CLI tools for coding agents: single commands that replace a flurry of `ls`, `find`, and `grep` to save turns and tokens and even preempt generated one-off scripts. They came back in Python. Every time. And they were pretty fast.
> 
> Then I wondered how far Java could go. So I measured. I built a set of small tools in Java, Go, Python, and Node, then compared startup time, code size, and how much steering it takes to get an agent to write Java. We'll look at where Java scripting started, what works today on JDK 25 and what it costs you, and what's still missing, including a few features I'd love to see land in the JDK.
> 
> Expect live demos, real measurements, and an honest scorecard, including the places where Java loses.
